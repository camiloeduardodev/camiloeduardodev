## Cheguei ao código pelo caminho mais longo

Comecei no **suporte técnico**. Passei por **QA**. Hoje construo **backend em C# e ASP.NET Core**.

Essa passagem deixou uma marca: **penso no que pode quebrar antes de escrever**. Projeto APIs REST, modelo dados em SQL Server e PostgreSQL com EF Core e cuido do ciclo inteiro — do banco ao deploy em Docker. Uso Clean Architecture e SOLID pelo que resolvem na prática, não como enfeite. E quando a entrega pede, viro full stack e levo a funcionalidade até a tela em React.

## Desenvolvimento assistido por IA

Agentes de código acoplados ao fluxo real de engenharia — **não como autocomplete**.

| | |
|---|---|
| **Agentes por papel** | Backend, frontend, DBA e code review, cada um com o contexto do domínio e os padrões do projeto |
| **MCP** | Model Context Protocol ligando os agentes a banco, repositório e ferramentas internas |
| **Spec-Driven Development** | A especificação é a fonte de verdade; o agente implementa e o gate de build/teste decide |
| **Automação de ciclo** | Revisão de código, geração de migrations, triagem de log e diagnóstico de produção |

> **O ganho não é digitar menos.** É varrer um legado inteiro antes de decidir, e chegar na causa raiz com evidência em vez de palpite.
